# RMU IMAGES
## VISUAL CONSTITUTION v1.0

### 1. PROPÓSITO

Este proyecto está dedicado a crear ilustraciones coherentes para un universo de fantasía medieval inspirado en Rolemaster y la Tierra Media.

Todas las imágenes deben compartir una identidad artística consistente, definida mediante referencias visuales y reglas de estilo incluidas en el proyecto:

* core.png
* generic-human-01.png

La prioridad absoluta es mantener la coherencia estética entre ilustraciones.

### 2. JERARQUÍA DE REFERENCIAS

Para cada generación se aplicará el siguiente orden de prioridad:

1. Instrucciones explícitas de la petición actual.
2. Imagen de referencia expresamente seleccionada por el usuario.
3. Imagen maestra core.png.
4. Reglas generales de esta Constitution.

Las imágenes generadas anteriormente no deben utilizarse como referencias visuales salvo petición explícita.

No se deben incorporar características estéticas procedentes de otras conversaciones o generaciones anteriores.

Si existe una contradicción entre la referencia visual seleccionada y las reglas generales, prevalecerá la referencia seleccionada, excepto cuando el usuario indique lo contrario.

### 3. IDENTIDAD ARTÍSTICA

Las ilustraciones deben parecer dibujos tradicionales realizados por un artista conceptual especializado en fantasía medieval oscura.

Características principales:

- Técnica de grafito y carboncillo.
- Trazos manuales visibles.
- Rayado irregular y sombreado mediante líneas cruzadas.
- Texturas orgánicas.
- Ausencia de acabados digitales excesivamente pulidos.
- Apariencia de ilustración artesanal.
- Atmósfera oscura y misteriosa.

### 4. PALETA CROMÁTICA

La paleta debe ser extremadamente limitada.

Colores predominantes:

- Negro profundo.
- Gris carbón.
- Gris azulado muy oscuro.
- Sepia desaturado para las zonas iluminadas.

Evitar:

- Colores vivos.
- Saturación elevada.
- Degradados digitales artificiales.
- Contrastes cromáticos excesivos.

### 5. ILUMINACIÓN

La iluminación debe ser dramática y contenida.

Características:

- Predominio de sombras profundas.
- Iluminación localizada.
- Transiciones irregulares entre luz y oscuridad.
- Áreas extensas sin información visual.
- Luz integrada en los trazos del dibujo.

En retratos se utilizará preferentemente iluminación cenital.

La iluminación debe revelar únicamente las formas necesarias para comprender la imagen.

### 6. TRAZO Y NIVEL DE DETALLE

El dibujo debe conservar una apariencia manual.

Se priorizarán:

- Trazos expresivos.
- Líneas imperfectas.
- Contornos parcialmente perdidos.
- Sombreado mediante grafito.
- Detalles sugeridos en lugar de completamente definidos.

Evitar:

- Hiperrealismo fotográfico.
- Contornos digitales perfectos.
- Texturas excesivamente uniformes.
- Detalles ornamentales innecesarios.

El nivel de detalle podrá variar según el tipo de ilustración.

### 7. COMPOSICIÓN

Las composiciones deben ser claras y centrarse en un elemento principal.

Principios:

- Jerarquía visual evidente.
- Fondos oscuros y discretos.
- Ausencia de elementos decorativos innecesarios.
- Uso deliberado del espacio negativo.
- Integración gradual de los elementos en las sombras.

Los elementos secundarios nunca deben competir visualmente con el sujeto principal.

### 8. CONSISTENCIA VISUAL

Cada imagen debe poder integrarse en una colección de ilustraciones sin parecer realizada mediante una técnica artística diferente.

No utilizar automáticamente la última imagen generada como referencia para la siguiente.

No introducir cambios de estilo basados en resultados anteriores.

La referencia maestra debe ser el punto de partida de cada nueva generación, salvo que se seleccione expresamente otra referencia.

### 9. AISLAMIENTO DE GENERACIONES

Cada petición debe considerarse una generación visual independiente.

El historial de la conversación puede utilizarse para comprender el contenido solicitado, pero no debe utilizarse para inferir nuevas características estéticas.

No acumular modificaciones estilísticas de generaciones anteriores.

No reinterpretar la referencia maestra basándose en resultados previos.

### 10. PROCESO DE GENERACIÓN

Antes de generar una imagen:

1. Identificar el sujeto solicitado.
2. Identificar la referencia visual autorizada.
3. Aplicar las reglas de esta Constitution.
4. Mantener la técnica, paleta e iluminación establecidas.
5. Evitar introducir elementos no solicitados.
6. Priorizar la coherencia estética sobre la complejidad.

Si la imagen maestra no está disponible para su utilización visual, no asumir que se ha consultado.

### 11. PRINCIPIO FUNDAMENTAL

La consistencia artística es más importante que la espectacularidad individual de cada ilustración.

Todas las imágenes deben parecer parte de un mismo libro de ilustraciones de fantasía medieval oscura.
